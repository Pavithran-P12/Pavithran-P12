01 / Client work

Frame OF Love.

A website for a wedding photography and film studio.

The question
How do you help couples feel a studio's work, understand what each package includes, and get in touch, all from a phone?
The build
A static site built with Astro and hosted under the studio's own domain. Story sections, three clearly compared packages with payment terms and delivery timelines, embedded wedding films, an Instagram-linked gallery, and pre-filled WhatsApp enquiries for each package. Images are served as WebP.
The thinking
Let the photographs lead and keep the words warm. Most couples browse on their phones and would rather chat than fill in a form, so every call to action opens a WhatsApp conversation that already says what they're asking about.

Astro / HTML / CSS / WebP / WhatsApp deep links

02 / Client work

ThirdSpace Play.

Everything needed to run a full badminton tournament, from the draw to the final.

The question
How do you run 103 doubles matches across five courts in a single day, and let every player and family member follow the scores from their phone?
The build
A mobile-first site built around a scheduling engine. It builds the day's fixtures automatically: nobody is ever on two courts at once, even players entered in two categories, and everyone gets rest between league matches. Group tables and the knockout bracket update from the results. Scorers unlock a court-side scoreboard with a passkey and score rally by rally, with golden-point league games and best-of-three knockouts. Finished matches become shareable result cards. The scoring and scheduling rules are covered by automated tests.
The thinking
Build lean for the event day, so it stays fast on patchy venue Wi-Fi, but shape it as an engine rather than a one-off page, so the same code can run the next tournament. A shared live backend is the next step.

JavaScript modules / HTML / CSS / Scheduling algorithm / Automated tests

03 / Client work

Smart Kids.

A website for a children's skill development centre that feels like a science expo.

The question
How do you make a learning centre exciting to children and trustworthy to parents, and turn a visit to the website into a booking?
The build
An animated Astro site built around one idea: every big idea starts as a doodle. A pencil rocket draws itself on notebook paper, gets coloured in with crayon, then lifts off as the page floods into space. The six programme groups become planets you travel past, a five-stage rocket lights up the teaching approach, and a “launch pass” booking form opens WhatsApp with the message already written. GSAP ScrollTrigger and Lenis drive the motion, and it's hosted on Cloudflare.
The thinking
Playful for children, simple for parents. The motion respects reduced-motion settings, everything still works without JavaScript, all the centre's details live in one data file so they're easy to update, and bookings need no server.

Astro / GSAP ScrollTrigger / Lenis / Cloudflare / WhatsApp booking

04 / Product

p12Vizha.

Run any event. Reuse everything. An event platform built for a hackathon.

The question
A college symposium, a sports tournament and a weekend workshop all need the same things: registrations, payments and confirmations. Why should organisers rebuild them every time?
The build
A multi-organisation event platform built with Next.js and Supabase during the Meta Global AI Developer Hackathon, using Meta's AI models. Organisers sign in with Google, set up an organisation and publish events with custom registration forms, capacity limits and duplicate protection. Participants pay through PayPal checkout (sandbox for now), webhooks confirm the payment, unpaid holds expire automatically, and a confirmation email goes out. Row-level security keeps each organisation's data apart, and unit and integration tests cover payments, validation and database boundaries.
The thinking
Treat registration, payments, schedules and check-in as reusable modules, so each new event is configuration, not code. Next up: AI that builds tournament brackets for any kind of competition.

Next.js / React / TypeScript / Supabase (Postgres, Auth, RLS) / PayPal / Resend / Vitest

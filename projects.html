01 / Client work

Frame OF Love.

A website for a wedding photography and film studio.

The question
How do you help couples feel a studio's work, understand what each package includes, and get in touch, all from a phone?
The build
A static site built with Astro and hosted under the studio's own domain. Story sections, three clearly compared packages with payment terms and delivery timelines, embedded wedding films, an Instagram-linked gallery, and pre-filled WhatsApp enquiries for each package. Images are served as WebP.
The thinking
Let the photographs lead and keep the words warm. Most couples browse on their phones and would rather chat than fill in a form, so every call to action opens a WhatsApp conversation that already says what they're asking about.

Astro / HTML / CSS / WebP / WhatsApp deep links

02 / Client work

ThirdSpace Play.

Everything needed to run a full badminton tournament, from the draw to the final.

The question
How do you run 103 doubles matches across five courts in a single day, and let every player and family member follow the scores from their phone?
The build
A mobile-first site built around a scheduling engine. It builds the day's fixtures automatically: nobody is ever on two courts at once, even players entered in two categories, and everyone gets rest between league matches. Group tables and the knockout bracket update from the results. Scorers unlock a court-side scoreboard with a passkey and score rally by rally, with golden-point league games and best-of-three knockouts. Finished matches become shareable result cards. The scoring and scheduling rules are covered by automated tests.
The thinking
Build lean for the event day, so it stays fast on patchy venue Wi-Fi, but shape it as an engine rather than a one-off page, so the same code can run the next tournament. A shared live backend is the next step.

JavaScript modules / HTML / CSS / Scheduling algorithm / Automated tests

This little corner

A personal website that leads with the work.

The question
What should a developer's website say about them? For me, the answer starts with the things they build and the care they put into them.
The build
An editorial portfolio made with semantic HTML, responsive CSS, and a small amount of JavaScript. Project stories, two themes, keyboard-friendly navigation, and reduced-motion support.
The thinking
Keep it light, make it personal, and let the content carry the experience. No framework needed for a small, mostly static site.

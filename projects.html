01 / Useful tools

InOfficeIQ.

A clearer way to plan a hybrid-working month.

The question
How many more days do I actually need to be in the office? Weekends, holidays, and changing plans make a simple requirement surprisingly hard to keep track of.
The build
An interactive calendar with office, work-from-home, and holiday selections. The calculations update as you plan, giving you an immediate view of working days and the office days still required.
The thinking
Keep the interaction direct: choose a day, see the effect. Put the calendar and the answer in the same place, without turning a personal planning tool into an enterprise dashboard.

02 / Useful tools

Weather App

Find the forecast. Get on with your day.

The question
What if checking the weather felt as simple as it should? A quick city search, useful conditions, and a readable forecast.
The build
A responsive web application that brings real-time weather data into a focused interface. Location search connects to a weather API to display temperature, humidity, and current conditions.
The thinking
Make the information hierarchy do the work. Give the current conditions space, keep the supporting data easy to scan, and adapt the interface to smaller screens.

03 / Experiments

ReadmePacman

A small automated detail with a lot of personality.

The question
Could a standard GitHub contribution graph become something more memorable, without adding another thing to maintain?
The build
A scheduled GitHub Actions workflow generates an animated Pac-Man contribution graph as an SVG and publishes it to an output branch, ready to embed in a profile README.
The thinking
Let automation take care of repetition. The output is playful; the workflow behind it is deliberately practical.

Sorting Hat

A personality quiz for the curious at heart.

The question
How do you make a short quiz feel like an experience, rather than a form?
The build
A Hogwarts-inspired Sorting Hat quiz with seven personality-based questions, a house-assignment result, and a themed, responsive interface.
The thinking
Use a clear progression and a distinctive atmosphere to make simple frontend logic engaging. A reminder that useful engineering can have a playful side.

05 / For the web

This little corner

A personal website that leads with the work.

The question
What should a developer's website say about them? For me, the answer starts with the things they build and the care they put into them.
The build
An editorial portfolio made with semantic HTML, responsive CSS, and a small amount of JavaScript. Project stories, two themes, keyboard-friendly navigation, and reduced-motion support.
The thinking
Keep it light, make it personal, and let the content carry the experience. No framework needed for a small, mostly static site.
